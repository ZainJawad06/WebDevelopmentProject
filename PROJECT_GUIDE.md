# MediRemind - Project Guide & Viva Reference

## 1. The Plan (Step 1)
- **Project Idea:** A modern dashboard medicine reminder and inventory web application designed for patients to track personalized prescriptions, scheduled timings, and real-time medicine stock quantities.
- **Features:**
  1. **Enter Specific Medicines:** Custom patient input for medicine name, dosage, schedule time, notes, and initial stock count.
  2. **Interactive Stock Tracking:** Visual stock progress bar on each prescription card with automatic decrement on intake and low-stock warning alerts.
  3. **Schedule Filter & Quick Search:** Filter by All Prescriptions, Pending, Taken, or Low Stock, plus instant name search.
  4. **Delete & Manage Reminders:** Instant deletion and intake undo support with database synchronization.
- **Supabase Table:**
  - Table: `medicines`
    - `id` (bigint, primary key, identity)
    - `created_at` (timestamp with time zone, default now())
    - `name` (text, not null)
    - `dosage` (text, not null)
    - `scheduled_time` (text, not null)
    - `stock` (integer, default 15)
    - `notes` (text, nullable)
    - `is_taken` (boolean, default false)

## 2. Supabase SQL & Client Confirmation

### Supabase SQL to Run
Run this SQL script in the **Supabase SQL Editor**:

```sql
-- Create medicines table with stock tracking
create table medicines (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  dosage text not null,
  scheduled_time text not null,
  stock integer default 15,
  notes text,
  is_taken boolean default false
);

-- If you previously created the table without the stock column, run this line:
alter table medicines add column if not exists stock integer default 15;

-- Enable Row Level Security (RLS)
alter table medicines enable row level security;

-- Create policy to allow public access (select, insert, update, delete)
create policy "Allow all operations for public users"
on medicines
for all
to public
using (true)
with check (true);
```

## 3. Viva Cheat-Sheet

### File-by-File Explanation
- **`index.html`**: The single HTML page hosting the root container, linking Google Fonts ('Plus Jakarta Sans') for a polished modern appearance, and mounting `src/main.jsx`.
- **`src/main.jsx`**: JavaScript entry point initializing React 19 via `createRoot`, rendering `App.jsx`, and importing global stylesheet `src/styles.css`.
- **`src/supabaseClient.js`**: Initializes and exports the Supabase client instance with hardcoded credentials for database read/write actions.
- **`src/App.jsx`**: Central controller component holding state (`medicineList`, `isLoading`, `currentFilter`, `searchQuery`), executing all Supabase queries, and orchestrating child components.
- **`src/components/Sidebar.jsx`**: Slim dark vertical navigation bar matching the reference dashboard UI, containing navigation icon buttons and active pill highlight.
- **`src/components/Navbar.jsx`**: Top header displaying patient greeting ("Welcome to MediRemind"), live search bar, notification bell, and user avatar.
- **`src/components/MedicineCard.jsx`**: Pastel prescription card (Yellow, Purple, Blue) rendering medicine name, dosage, stock progress track, and the coral "Take Dose" action.
- **`src/components/MedicineList.jsx`**: Schedule list table component displaying timings, intake completion bullets, stock tags, and delete actions.
- **`src/components/MedicineForm.jsx`**: Sleek dark card panel allowing patients to input specific medicine details, scheduled hour, and starting stock.
- **`src/components/Footer.jsx`**: Bottom canvas footer providing a medical safety disclaimer and framework credits.
- **`src/styles.css`**: The sole global stylesheet containing reference color tokens (coral, pastel yellow/purple/blue, dark slate), responsive breakpoints, and CSS keyframe animations.
- **`.gitignore`**: Excludes dependencies (`node_modules`) and build artifacts from version control.
- **`README.md`**: Project overview and installation steps for team members and evaluators.

### How Icons Work
Icons are imported from `lucide-react` as standard React functional components (e.g. `<Pill />`, `<Clock />`, `<Check />`). They render clean inline SVG vectors into the HTML without downloading image assets. You change their visual appearance directly with `size` (number in pixels) and `color` (hex string) props.

### How Animations Work
- **`pageFadeIn`**: Animates the `.dashboard-shell` from opacity `0` and scale `0.99` to `1.0` in 0.35s on initial mount for a soft app entrance.
- **`slideUp`**: Animates `.prescription-card` upwards from `translateY(10px)` with opacity fade-in over 0.3s when items load.
- **`spin`**: Rotates the `.state-spinner` loader SVG 360 degrees infinitely during Supabase network transactions.
- **CSS Transitions**: Elements like `.btn-continue`, `.filter-pill`, and `.sidebar-btn` have 0.15s `transition` on `background-color`, `transform`, and `box-shadow` for tactile responsiveness.
