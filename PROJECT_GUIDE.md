# MediRemind - Project Guide & Viva Reference

## 1. The Plan (Step 1)
- **Project Idea:** A modern full-screen Neobrutalist medicine reminder and inventory web application designed for patients to track personalized prescriptions, scheduled timings, and real-time medicine stock quantities using pure HTML, CSS, and vanilla JavaScript.
- **Features:**
  1. **Enter Specific Medicines:** Custom patient input for medicine name, dosage, schedule time, notes, and initial stock count.
  2. **Interactive Stock Tracking:** Visual stock progress bar on each prescription card with automatic decrement on intake and low-stock warning alerts.
  3. **Schedule Filter & Quick Search:** Filter by All Prescriptions, Pending, Taken, or Low Stock, plus instant name search.
  4. **Multi-Section Views:** Interactive sidebar allowing switching between Overview Dashboard, Full Schedule, Stock & Inventory, and Saved Prescriptions.
  5. **Delete & Manage Reminders:** Instant deletion and intake undo support with database synchronization.
- **Supabase Table:**
  - Table: `medicines`
    - `id` (bigint, primary key, identity)
    - `created_at` (timestamp with time zone, default now())
    - `name` (text, not null)
    - `dosage` (text, not null)
    - `scheduled_time` (text, not null)
    - `stock` (integer, default 15)
    - `notes` (text, nullable)
    - `is_taken` (boolean, default false)
- **Files Created:**
  - `index.html` (single comprehensive HTML file containing structure, layout, and vanilla JavaScript logic)
  - `styles.css` (single comprehensive CSS file with full-screen Neobrutalism design, color palette, and CSS animations)
  - `README.md`
  - `PROJECT_GUIDE.md`

## 2. Supabase SQL & Client Confirmation

### Supabase SQL to Run
Run this SQL script in the **Supabase SQL Editor**:

```sql
-- 1. Create medicines table with stock tracking
create table medicines (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  dosage text not null,
  scheduled_time text not null,
  stock integer default 15,
  notes text,
  is_taken boolean default false
);

-- If you previously created the table without the stock column, run this line:
alter table medicines add column if not exists stock integer default 15;

-- 2. Enable Row Level Security (RLS)
alter table medicines enable row level security;

-- 3. Create policy to allow public access (select, insert, update, delete)
create policy "Allow all operations for public users"
on medicines
for all
to public
using (true)
with check (true);
```

## 3. Viva Cheat-Sheet

### File-by-File Explanation
- **`index.html`**: The single HTML page hosting the complete web application structure, user interface layout, Supabase client integration via CDN, and vanilla JavaScript functions for state, stock tracking, and local/cloud synchronization.
- **`styles.css`**: The sole global stylesheet declaring CSS variables, full-screen flex/grid layouts, Neobrutalist stark black borders, hard unblurred drop shadows, and tactile button animations.
- **`README.md`**: Project overview and quick start guide explaining how to open the application directly in any browser with zero installation steps.

### How Icons Work
Icons are powered by the official **Lucide Icons CDN library** (`https://unpkg.com/lucide@latest`). HTML elements include `data-lucide="icon-name"` (such as `<i data-lucide="pill"></i>` or `<i data-lucide="check"></i>`). The JavaScript calls `lucide.createIcons()`, which dynamically converts each element into an inline, crisp SVG graphic with pure vector scaling.

### How Animations Work
- **`pageFadeIn`**: Animates `.dashboard-shell` from opacity `0` to `1` over 0.3s when the page initially mounts.
- **`slideUp`**: Smoothly shifts `.prescription-card` and `.status-notification-banner` upwards by 8px while fading them in.
- **`spin`**: Continuously rotates the loading spinner icon 360 degrees in an infinite linear loop during network requests.
- **Neobrutalist Tactile Press Transitions**: On hover, cards and buttons translate up by `(-2px, -2px)` with expanded offset shadows (`4px 4px 0px #000`). On `:active` click, they press down by `(2px, 2px)` with shadows collapsing to zero for physical tactile feedback.
